# Biology visual upgrade batch 01

SA-0001–SA-0025: 25 separately checked concept laboratory routes. Each has a 100-second staged demonstration and guided player. Shared scientific models retain their units and limitations.

The batch adds structure-specific anatomy, original surface detail, shaded 2D specimens, smoother curved geometry, route-following motion streaks and theatre structure inspection. Digestive geometry connects oesophageal, gastric, duodenal and ileocaecal regions without routing food through the liver. Three legacy viewers gain matched neuronal, spindle and lung detail.

A browser issue surfaced during repeated route checks: disposable capability probes and synthetic context losses could cause WebKit to block subsequent WebGL contexts. The real renderer now establishes support, and renderer disposal releases resources without forcing a synthetic loss on every unmount. The working 2D fallback remains available. Final review used localhost after the earlier browser session blocked the 127.0.0.1 origin.

## Review evidence

Guided playback was checked separately on all 25 routes.

This is an internal selected-state review, not independent scientific certification or a claim that all 408 concepts have received this new visual upgrade. The next batch starts at SA-0026.
