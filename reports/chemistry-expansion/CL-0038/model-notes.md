Twenty-four rounded representative aggregates encode residue volume using the declared reference solid densities. For visualization only, phase volumes are assumed additive: liquid reference volume=initial water volume+D/ρsolid; the solid occupies residue/ρsolid. This treats dissolved material's partial volume as the solid reference specific volume; real solution contraction/expansion and density are not predicted. No calibrated volume reading is offered. The outer liquid mesh includes an inward cavity for each residue aggregate, avoiding overlapping liquid/solid interiors.
