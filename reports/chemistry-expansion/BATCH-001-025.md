# Chemistry Labs · first 25 reviewed investigations

Frontend-only Science Atlas extension. The catalogue lists 270 distinct Class 1–12 investigations. Only the first 25 are marked implemented and internally reviewed; the remaining 245 are development plans. Class paths are editorial, not certified official board mappings.

The sidebar provides class selection, search, build-status filtering and the complete CSV list. Each reviewed investigation has a topic-specific numerical/conceptual model, 2D/3D viewers, a 100- or 110-second guided explanation, manual controls, observations, worked substitutions where applicable, an exam-style HTML report and retained browser notes. Scientific limitations are shown in each lab. No API key or backend is required.

## Evidence and scope

Each lab folder contains its source-hashed internal review and browser/model/practical evidence. The completion ledger validates every ready entry against those hashes. Viewports reviewed include phone, tablet, laptop and TV; these are browser-size checks, not physical-device certification. Model consistency is not independent expert certification. External scientific reference basis is retained in private development notes, not presented as source/referral links in the product.

The current worktree passed 1,903 regression tests and 213 chemistry tests. An isolated candidate checkout passed 1,863 tests, the existing 408-concept/practical and inventory checks, TypeScript, and the GitHub Pages production build. Its application source/configuration/data/tests/static-asset blob manifest is compared with the final commit before publication. The unrelated 146 staged files are excluded and preserved; existing committed science improvements are retained.
